# MERN Engineering

> A practical journey through the MERN stack, from core concepts to building and deploying full-stack applications.

This repository covers the MERN stack from the basics to building complete full-stack applications.

The focus is on understanding how each part of the stack works, how they connect, and how to build projects with them.

## Overview

MERN stands for:

- MongoDB
- Express
- React
- Node.js

This repository is a step-by-step study of the MERN stack, starting with the basics and moving toward complete full-stack applications.

Topics include:

- JavaScript
- React
- Node.js
- Express
- MongoDB
- REST APIs
- Authentication
- State management
- Frontend and backend integration
- Testing
- Deployment
